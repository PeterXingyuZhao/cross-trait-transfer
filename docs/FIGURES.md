# Reproduce the figures

There are two plotting workflows. **Redraw the included paper measurements** to
reproduce the numerical panels on CPU, or **plot a fresh experiment** after
generating data, fine-tuning students, and measuring recovery and metrics on GPUs.
The table below uses the figure numbering of this release's measurement bundle.
Some implementation filenames retain older figure numbers. If a later manuscript
renumbers or replaces panels, that correspondence must be checked separately.

| Figure | Panels supplied here | Measurements needed for a fresh run |
| --- | --- | --- |
| 1B/C | Color-transfer network and six-group summaries | 30-color number SFT; student recovery, Metric 1, and Metric 4 |
| 2 | Transfer across models and carriers | Eight model/carrier settings; train each teacher-conditioned student and evaluate recovery |
| 3 | Agreement of six metrics with measured transfer | Twelve Qwen2.5 settings; student recovery and Metrics 1–6 |
| 4A–C | Changes during training | Intermediate student checkpoints; recovery matrices, effective ranks, and agreement with predictive metrics |
| 4D | Control-relative vermilion recovery | Four red-hue teachers and an unnamed-color control; dense checkpoint recovery |
| 5 | Transfer from aligned and opposed trait pairs | 50 aligned and 50 opposed color pairs plus a shared trained control |

Figure 1A is a conceptual illustration and is not generated by this repository's
plot command. The command does not recreate the manuscript PDF or every appendix
figure. See [EXPERIMENTS.md](EXPERIMENTS.md) for the experiment configurations
and [the source map](../scripts/README.md) for rendering implementations.

## 1. Redraw the saved paper measurements on CPU

Run all commands from the repository root with Python 3.12:

```bash
python3.12 -m venv .venv-analysis
source .venv-analysis/bin/activate
python -m pip install -r requirements/cpu.txt
python tools/validate_release.py
python run.py plot --saved-paper-data
```

To draw just one figure, or use a different output directory:

```bash
python run.py plot --saved-paper-data --figure 3
python run.py plot --saved-paper-data --figure 4 --output outputs/dynamics-figure
```

`--figure` accepts `all` (the default), `1`, `2`, `3`, `4`, or `5`. A single
number selects the entire supplied layout for that figure, not an individual
panel. `--output` is the parent directory; the second example writes inside
`outputs/dynamics-figure/figure4/`. Existing files at the selected destination
are replaced, so choose a new directory to retain an earlier rendering.

The input bundle is `data/figures/figure1.json` through `figure5.json`, plus
`network_label_layout.json` for Figure 1 label placement. The default outputs are:

| Directory under `outputs/figures/` | Plot filenames (`{pdf,png,svg}` means all three formats) | Numerical/provenance file |
| --- | --- | --- |
| `figure1/` | `color_token_sft_network_heatmaps_row.{pdf,png,svg}` | `color_token_sft_network_heatmaps_row.json` |
| `figure2/` | `sl_matrix_sweeping.{pdf,png,svg}` | `provenance.json` |
| `figure3/` | `qwen25_metric_agreement_all900.{pdf,png,svg}` | `recomputed_correlations.json` |
| `figure4/` | `figure4_training_dynamics.{pdf,png,svg}` | `recomputed_trajectory.json` |
| `figure5/` | `random_color_pairs_main.{pdf,png,svg}` | `recomputed_pair_statistics.json` |

The renderer recalculates centering, group summaries, correlations, trajectory
statistics, or pair summaries from the supplied measurements, depending on the
figure. Where stored comparison values are provided, disagreement raises an
error rather than silently drawing a changed result. Fonts and rendering may
differ between platforms; the checks concern numerical agreement, not
byte-identical image or PDF files.

This route does not sample teacher responses, train students, or score model
probabilities and activations. In particular, redrawing a saved Metric 1 matrix
does not recompute its per-prompt signatures. Fresh Metric 1 requires the matched
probability caches described in [METRICS.md](METRICS.md); an aggregate legacy
matrix cannot recover the current mean-per-prompt cosine.

## 2. Plot matrices from your own measured experiment

Complete the generation, training, recovery, and metric steps in
[REPRODUCING.md](REPRODUCING.md). Then point `analyze` to the same output directory
used by `python run.py metrics`:

```bash
python run.py analyze --metrics-dir outputs/color-metrics
```

If you kept the default metric output location, use
`<training-output-dir>/paper_metrics` instead. The directory must contain the
completed `summary.json`, `matrices.npz`, and referenced metric CSV files from
the metric workflow. A training checkpoint directory alone is not sufficient.

This CPU command checks label order, CSV hashes, CSV/NPZ consistency, and
complete-matrix correlations. It then writes:

```text
outputs/color-metrics/plots/
  measured_matrices.pdf
  measured_matrices.png
  metric_agreement.pdf
  metric_agreement.png
```

The matrix figure contains recovery and the metrics selected in your run, with
independent color scales. The agreement chart uses all entries after
double-centering both complete matrices. Set `--output outputs/my-analysis` to
write directly to another folder. This command produces diagnostic layouts for
your run; it does not assemble the multi-experiment paper layouts.

## 3. Assemble the main layouts from new measurements

Use a new measurement directory with the same JSON schema as `data/figures/`:

```bash
python run.py plot --data-dir data/my-figure-measurements --figure 3 --output outputs/my-paper-figures
```

For one selected figure, provide its `figureN.json`; Figure 1 also needs
`network_label_layout.json`. For `--figure all`, provide all five JSON files and
the label layout. Keep your custom input directory inside the repository for
compatibility with the Figure 2 provenance writer.

There is currently no command that automatically converts a collection of
fresh experiment outputs into this complete figure bundle. Assemble the
required settings/checkpoints, matrix label orders, and corresponding summary
fields first. The supplied JSON files are schema examples: replace measurements
and their provenance together, and recalculate their expected summaries. The
renderer validates stored summaries against the matrices; it will reject stale
summary fields. Keep custom inputs separate from the saved paper bundle.

Two additional workflows provide plots directly from completed fresh reports:

- **Dense training dynamics:** follow [DYNAMICS.md](DYNAMICS.md). Its report writes
  an interactive `index.html`, `analysis.json`, and `trajectories.csv` under
  `outputs/dynamics/report/`. The `vermilion` condition's
  `control_adjusted_gain` against `step` supplies Figure 4D; the report's full
  layout also shows the other target conditions.
- **Random color pairs:** finish all 101 conditions in the
  [random-pair workflow](../experiments/random_pairs/README.md), then run from the
  repository root:

```bash
python -m scripts.plot_paper_random_pairs_v41 \
  --source experiments/random_pairs/runs/report/summary.json \
  --output outputs/fresh-random-pairs --full-width
```

The pair command writes `random_color_pairs_main.pdf`, `.png`, and `.svg`, plus
`random_color_pairs.data.json`. `--full-width` matches the layout selected by
the saved-paper renderer. The provenance file records the report hash, summaries,
and plotting settings. A partial set of pairs is not the complete Figure 5
experiment.

## Matrix orientation and aggregation

Preserve the ordered trait labels and the orientation specified by each input.
The Figure 3 and fresh metric workflow use teacher rows and answer columns.
The Figure 1, 2, and 4 bundles use answer rows and teacher columns. Check those
labels before transferring matrices between workflows.

- Figure 1 double-centers complete matrices and scales by off-diagonal RMS.
  Six-group blocks exclude self-pairs but retain other within-group entries.
- Figure 2 centers complete matrices before calculating group contrasts.
- Figure 3 double-centers both complete matrices and correlates all 900 entries.
- Figure 4 computes energy effective rank on uncentered recovery matrices and
  centers full matrices before selecting 870 off-diagonal correlation entries.
- Figure 5 weights all pairs equally. Repeated colors and the shared trained
  control are not independent replications; the plot does not infer seed-level
  significance or confidence intervals.

Use the current mean of per-prompt cosines for Metric 1. Preserve the carrier,
neutral reference, teacher set, prompt count, and shared prompt weights for the
chosen setting. Fresh stochastic experiments need not reproduce the saved
measurements bit for bit. [VALIDATION.md](VALIDATION.md) records the checks run
during release preparation and the GPU work not repeated there.
